LearnLoop Vercel deployment notes

This package adds a root-level app.py entry point for Vercel and makes the
temporary upload/database directories writable under Vercel.

IMPORTANT LIMITATION:
Vercel serverless functions do not provide durable local disk storage.
On Vercel, this build places SQLite at /tmp/learnloop.db and uploaded videos
at /tmp/learnloop-uploads so the app can start for a limited demonstration.
These files are temporary and can disappear; separate function instances
may not share them. Therefore user accounts, profiles, exchanges, videos and
certificates are NOT production-persistent on this configuration.

For a real public deployment, configure a hosted PostgreSQL database and
persistent object storage for uploaded videos, then set DATABASE_URL (or
adapt the DB connection) and the video-storage provider credentials.
Do not upload your local Backend/learnloop.db or secrets to GitHub.

Local development remains unchanged:
    cd Backend
    py app.py
